# 项目规则与说明

## 项目背景
本项目是一个技术验证项目 (PoC)，旨在测试 **人大金仓 (Kingbase) Oracle 版数据库** 的可用性和可靠性。

## 开发环境
- **开发语言**: C#
- **目标框架**: .NET 8
- **容器化**: Docker

## 部署与打包
- 项目需支持 Docker 容器化部署。
- Dockerfile 应存放在项目根目录或对应的源码目录下。
- 镜像构建应基于官方 .NET 运行时镜像。

## 目录结构说明
- **src/**: 存放项目的源代码。
- **skills/**: 需要 AI 注意的技能或工具集代码（如 AI 插件、特定业务逻辑封装等）。
- **test/**: 存放单元测试和集成测试代码。
- **docs/**: 存放项目文档、测试报告等。
- **.trae/**: 存放项目规则、IDE 配置及 AI 助手上下文信息。

## 编码规范
- 遵循 C# 标准编码规范。
- 所有的文档文件名和内容描述应使用中文。
- 单元测试生成需按需进行，不自动每次生成。
- 编译时不自动运行单元测试，需按需运行。
