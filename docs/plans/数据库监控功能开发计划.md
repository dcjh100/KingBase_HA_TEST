# 数据库监控功能开发计划

## 1. 任务概述
本计划旨在落实《数据库监控功能设计方案》，开发一套可视化的 Web 监控界面，用于验证 Kingbase 数据库的高可用配置、读写分离及负载均衡能力。

## 2. 任务分解

### 阶段一：后端核心逻辑开发 (Backend)
**目标**：提供可靠的数据探测 API。

- [ ] **任务 1.1: 创建 MonitorController**
    - 位置: `src/KingBaseTest.Web/Controllers/MonitorController.cs`
    - 内容: 继承自 `Controller`，注入 `IConfiguration`。
- [ ] **任务 1.2: 实现 CheckHealth 接口**
    - 路由: `GET /Monitor/CheckHealth`
    - 参数: `string mode` ("primary", "standby", "loadbalance")
    - 逻辑:
        - 根据 `mode` 获取或构造对应的连接字符串。
        - 针对 `loadbalance` 模式，动态追加 `Pooling=false`。
        - 执行 SQL 获取 `inet_server_addr`, `transaction_read_only` 等信息。
        - 记录查询耗时。
        - 返回统一的 JSON 格式数据。

### 阶段二：前端界面开发 (Frontend)
**目标**：提供直观的三列式全景仪表盘。

- [ ] **任务 2.1: 创建视图页面**
    - 位置: `src/KingBaseTest.Web/Views/Monitor/Index.cshtml`
    - 布局: 使用 Bootstrap Grid System 实现三列布局。
    - 组件:
        - 顶部控制栏 (开始/停止/频率)。
        - 三个独立面板 (Primary, Standby, LoadBalance)。
        - 底部日志区域。
- [ ] **任务 2.2: 实现前端交互逻辑**
    - 技术: jQuery, AJAX。
    - 逻辑:
        - 实现 `startAllMonitors()` 和 `stopAllMonitors()`。
        - 使用 `setInterval` 并行触发三个通道的探测请求。
        - 实时更新各面板的状态指示灯、IP 显示、耗时。
        - **重点**: 实现 LoadBalance 通道的 IP 分布统计 (计算百分比并渲染进度条)。

### 阶段三：集成与测试 (Integration & QA)
**目标**：验证功能闭环。

- [ ] **任务 3.1: 导航集成**
    - 修改 `_Layout.cshtml`，添加 "数据库监控" 菜单入口。
- [ ] **任务 3.2: 功能验证**
    - 启动应用，访问监控页面。
    - 点击 "启动监控"。
    - **验证点**:
        - Primary 面板 IP 是否稳定？(预期：稳定)
        - Standby 面板 IP 是否稳定？(预期：稳定)
        - LoadBalance 面板 IP 是否跳变？(预期：跳变)
        - 读写状态是否正确显示？(Primary: on/off, Standby: on)

## 3. 时间表
- **预计耗时**: 2-3 小时
- **里程碑**: 完成所有功能并提交代码。
